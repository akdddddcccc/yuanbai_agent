# 元白楼实拍材质

这些贴图由用户在元白楼现场拍摄的照片生成，用于本项目的网页 GLB 模型。

- `concrete-*`：灰色粗糙墙面实拍，保留砂粒、微孔和轻微色差。
- `brick-*`：元白楼红砖墙实拍，保留砖缝、擦痕和不均匀砖色。
- `painted-steel-*`：橙红涂层钢构实拍，锈蚀参考仅用于少量掉漆和暗点。

`assets/materials/yuanbai-site/*-source.png` 是依据现场照片通过图像工具整理的材质样片，原始照片保持不变；样片存放在非公开资源目录，不随网页打包。当前目录的 `*-albedo.jpg`、`*-normal.jpg` 和 `*-roughness.png` 是网页模型使用的 768 像素轻量 PBR 贴图。法线与粗糙度是基于图像细节的美术估计，不是摄影测量或实测扫描。

`steel-muted-albedo.jpg` 对橙红涂层钢构降低饱和度与亮度，使钢架以暗色钢材为主，掉漆与磨损仍沿用实拍细节。
